# Jani Fu

A school janitor's evil administrator bosses have turned into monsters.
Punch and kick them down, jump over innocent kids in the halls, and beat
the Principal boss at the end of each level.

## Play

Open `index.html` in a browser, or play it hosted via GitHub Pages:
https://oakcroatin.github.io/Jani-Fu/

## Local dev

Everything is a single self-contained page (`index.html`) plus `images/`
and `audio/`. No build step — just open the file or serve the folder with
any static file server.

Leaderboard scores are stored locally in the browser (`localStorage`) —
scores don't sync between devices or browsers.
